Add a New Sound

  • Click the Add Sound tab in the top navbar.
  • Drag & drop any audio file (MP3, WAV, OGG, FLAC) or click Browse Audio File.
  • Sound name is auto-extracted from filename — edit freely.
  • Pick an Emoji 🎮 and a color theme.
  • Assign a hotkey shortcut (e.g. 1 A Space).
  • Click Save Sound to finish.
2

World Share vs Only Me

  • World Share ✅ Checked: Sound is public — everyone online can see & play it.
  • Unchecked ☐: Sound is private in your local browser only (Only Me).
  • Play Soundboard page has separate World and Only Me tabs.
  • Import any World sound to your local library using the Import button.
3

Route Audio to Discord / Game (VB-Cable)

  • Download free driver: vb-audio.com/Cable
  • In the header Output dropdown → select CABLE Input.
  • In Discord/Game settings set Microphone → CABLE Output.

Admin Mode — Master Control

  • Click the Admin Mode button in the header.
  • Default passcode: UG1 — change it after first login.
  • Admin can Edit & Delete World sounds freely.
  • Regular users cannot edit World sounds — protected!

How it works with Games & Discord

Once installed, route your soundboard and microphone seamlessly:

1
Install Virtual Cable Driver:
Click the button above to run INSTALL_DRIVER.bat (or download from vb-audio.com).
2
In Ultra Soundboard (Header above):
Audio Output will auto-select CABLE Input (VB-Audio Virtual Cable).
3
In Game / Discord Voice Settings:
Set Microphone (Input Device) to CABLE Output (VB-Audio Virtual Cable).
4
Click the Mic Button:
1st Click (Dual Voice): Real Voice + Soundboard play together into Game/Discord!
2nd Click (Sound Only): Real Voice is muted, ONLY soundboard sounds play into Game!

Dual Voice vs Sound Only Mic Modes:

  • 🎙️ Sound Only Mic: Mutes your physical mic so players/friends ONLY hear soundboard sound effects.
  • 🎧 Dual Voice + Sound: Captures your real microphone voice AND soundboard effects together in real-time!
